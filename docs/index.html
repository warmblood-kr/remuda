Nightly channel
Install Remuda.
The local Remuda README says a stable release has not been published; the commands below explicitly select nightly.
Before installing Butler, check the Remuda runtime version with remuda --version. Butler recommends 0.1.0-nightly.20261001000710.0a5f090 or later; older cores boot Butler through a fallback (see the Butler README).

        

          
Linux and macOS

          
curl -fsSL https://warmblood-kr.github.io/remuda/install.sh | REMUDA_CHANNEL=nightly sh

          
Windows · PowerShell

          
$env:REMUDA_CHANNEL='nightly'; irm https://warmblood-kr.github.io/remuda/install.ps1 | iex

          
Then install Butler

          
remuda mod install warmblood-kr/remuda-butler
remuda butler --agent codex

          
For Claude, use remuda butler --agent claude. Check the Remuda README and Butler README for current install and compatibility guidance.
